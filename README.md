# 💼 Lukas Fritsch – Personal Website

This is the source code for [www.lukas-fritsch.de](https://www.lukas-fritsch.de), my personal portfolio and professional homepage.  
It showcases my work as a Fullstack Developer, UX Designer, and Gamification Enthusiast.

## 🌐 Tech Stack

- **React** (with `react-router-dom`)
- **Tailwind CSS** for styling
- **ReactPlayer** for video background
- **Component-based layout** with modular structure

## ✨ Features

- Animated hero section with video background
- Responsive design using Tailwind CSS
- Smooth modal navigation for project previews
- About Me, Skills, and Project References
- Static legal pages (Privacy, Imprint)
- Contact links (LinkedIn, Email)


## 🛠️ Deployment

The site is deployed on render.com
